# xomtra.com

Static website for [Xomtra](https://github.com/xomtra/xomtra), long-term memory for Home Assistant.

- One page per language: `/` (en), `/de/`, `/cs/`, `/pl/`, `/nl/`
- No build step, no tracking, no cookies. Served by Cloudflare Pages; security headers in `_headers`.
- Launch switch: `LAUNCHED` in the page script (`false` = "public beta coming soon").

Contact: support@xomtra.com
